# Sample data provenance

`demo_records.json` is a temporary demonstration dataset generated by `tracecheck.demo_data.build_demo_records()`.

It is not the original CRIMEATHON raw evidence archive.

- The V-0412 case-summary fixture preserves the request ID, change ID, vendor, field, timestamp and blank approval reference stated in the Tier 2 presentation. The original E18 row identifier was not present in the presentation, so the demo API row ID is a generated fixture ID.
- The other 70 API/change pairs are synthetic records created to reproduce the reported 71/71 count and exercise ProofPath. Their identifiers, vendors, times and approval references are not original case evidence.
- E04 is a case-summary fixture based on the presentation's description of key-tb-07. It is not the original credential register.
- E02's ten export rows, E01's large-export volume, E05's finance-path access details, and E03/E15/E20 context rows are synthetic examples based on the presentation's high-level notes. Do not cite their generated row details as original evidence.
- `evidence_catalog.json` describes the 20 evidence-item references at the level supported by the presentation. A catalog entry is not the source evidence itself.

Every seeded record carries `record_origin` so the UI can display its provenance. User imports default to `imported` unless the source file explicitly provides a provenance field.
